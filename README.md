<h1 align="center">Elektryczny Terminator</h1>

<p align="center">
  Ewidencja sprzętu ochronnego i terminów jego legalizacji.<br>
  Windows · Linux · Android · działa bez internetu
</p>

---

Elektryczny Terminator pilnuje terminów badań rękawic, drążków, wskaźników napięcia, uziemiaczy i reszty sprzętu
ochronnego. Każda sztuka ma swój termin liczony od ostatniego badania, a program kolorami pokazuje, co jest ważne,
co trzeba zaplanować i czego nie wolno już używać.

## Pobieranie

Najnowsza wersja jest w zakładce **[Releases](../../releases/latest)**:

| Plik | Do czego |
|---|---|
| `…_x64-setup.exe` | instalator dla Windows 10/11 — bez uprawnień administratora i bez internetu |
| `…_x64_pl-PL.msi` | instalator dla Windows dla wszystkich użytkowników komputera (wymaga administratora) |
| `…_amd64.AppImage` | Linux (Ubuntu 24.04, Linux Mint 22) — nadaj prawo uruchamiania i uruchom |
| `…_amd64.deb` | Linux — pakiet do instalacji |
| `ElektrycznyTerminator.apk` | aplikacja na telefon z Androidem |
| `Instrukcja obsługi.pdf` | pełna instrukcja ze zrzutami ekranu |

Windows może pokazać ostrzeżenie „System Windows ochronił ten komputer” — program nie ma płatnego podpisu cyfrowego.
Kliknij *Więcej informacji* → *Uruchom mimo to*.

## Co potrafi

- **Pulpit** — co jest po terminie, pilne i co się zbliża; sprzęt w laboratorium z liczbą dni.
- **Kolory statusów** i pasek pozostałego okresu legalizacji przy każdej sztuce.
- **Obiekty → rozdzielnie, pracownicy, rodzaje sprzętu** z własnym okresem badań i progami ostrzeżeń.
- **Wysyłka do badania i przyjęcie z badań** — lista do odhaczania protokół po protokole, ze skanem protokołu.
- **Plan badań** na miesiąc z wydrukiem protokołu przekazania i **plan roczny** na kartce A4.
- **Etykiety QR** na dowolnym arkuszu naklejek, obsługa skanera USB.
- **Załączniki** — skany protokołów, także jeden plik do wielu sztuk naraz.
- **Praca kilku osób** na wspólnej bazie w folderze sieciowym, z ochroną przed nadpisaniem cudzych zmian.
- **Role użytkowników**, dziennik zmian, archiwum, import i eksport Excela, kopie zapasowe z przywracaniem.
- **Aplikacja na telefon** — skanowanie etykiet, podgląd statusów offline i obchód rozdzielni (spis z natury).

Szczegóły i zrzuty ekranu: **[Instrukcja obsługi](Instrukcja%20obsługi.pdf)**.
